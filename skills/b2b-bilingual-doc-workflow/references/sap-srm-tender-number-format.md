# SAP SRM 招标公告数字格式（俄语区域）

## 问题

SAP SRM 系统导出的招标公告 PDF（`0.PDF`）中，`Количество`（数量）字段使用**俄语区域数字格式**：

| 符号 | 俄语含义 | 英语含义 |
|:-----|:---------|:---------|
| `.` (点) | **千分位分隔符** | 小数点 |
| `,` (逗号) | **小数点** | 千分位分隔符 |

**与英语习惯完全相反。**

## 实例

| SAP 输出 | 俄语解读 | 正确数值 | ❌ 错误解读 |
|:---------|:--------|:--------|:-----------|
| `4.800,000` | 4,800.000 | **4,800** | 4,800,000 或 4.8 |
| `8,000` | 8.000 | **8** | 8,000 |
| `12.500,000` | 12,500.000 | **12,500** | 12,500,000 |
| `1.200,500` | 1,200.500 | **1,200.5** | 1,200,500 |

## 判断方法

1. **俄语 PDF 中的数字永远按俄语规则解读**：`.` = 千分位，`,` = 小数点
2. **交叉验证**：对照图纸 BOM 中单台数量和招标总量是否成比例关系
3. **金额同理**：`53 000,00` = 53,000.00（不是 53,000,00）
4. **单位后缀**：注意 `ШТ`（件）、`К-т`（套/组）等，`К-т` 表示按套供货，需拆解 BOM 后计算各零件数量

## 图纸中的逗号

GOST 图纸标题栏和 BOM 表中的重量/尺寸也用逗号作小数点：

| 图纸原文 | 含义 | 写入询价表 |
|:---------|:-----|:----------|
| `0,05` | 0.05 kg | 0.05 |
| `85,5` | 85.5 mm | —（尺寸，不写入） |
| `Масса 0,02` | 重量 0.02 kg | 0.02 |

## 工作流 B 集成点

在 B1（读招标公告）阶段，提取 `Количество` 后**必须**按本规则转换后再写入询价表。转换逻辑：

```python
def ru_number_to_float(s: str) -> float:
    """'4.800,000' -> 4800.0"""
    s = s.replace(' ', '')      # 移除空格
    s = s.replace('.', '')       # 移除千分位点
    s = s.replace(',', '.')      # 逗号→小数点
    return float(s)
```
