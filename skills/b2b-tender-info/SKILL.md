  ## 工作流程

  ### Phase 1 — 需求确认
  与用户确认以下信息（至少 3 项）：
  1. **产品/品类**：具体的产品名称、HS 编码（如有）
  2. **目标国家/区域**：具体国家或"全球"
  3. **预算范围**（可选）：金额范围，如 $50K-$500K
  4. **招标类型**（可选）：政府采购 / 企业采购 / 国际金融机构项目
  5. **截止时间**（可选）：只看 7 天内 / 30 天内截止的
  6. **关键词语言**：中英文搜索词（外贸场景建议中英文各一套）

  如果用户信息不足，先主动问清楚再开始搜索。

  ### Phase 2 — 招标平台搜索策略

  #### 2.1 国际免费平台（首选）

  | **dgMarket (World Bank)** | `site:dgmarket.com {product}` | 搜索世行/联合国项目 |
  | **UNGM (UN Global Market)** | `site:ungm.org {product}` | 联合国采购 |
  | **TED (EU Tenders)** | `site:ted.europa.eu {product}` | 欧盟招标（TED 最大公共采购数据库） |
  | **African Development Bank** | `site:afdb.org tender {product}` | 非洲开发银行项目 |
  | **Asian Development Bank** | `site:adb.org tender {product}` | 亚开行项目 |
  | **DevelopmentAid** | `site:developmentaid.org tender {product}` | 国际发展项目 |
  | **GlobalTenders** | `site:globaltenders.com {product}` | 全球招标聚合 |

  #### 2.2 国别/区域平台
  | 区域 | 搜索方法 |

  #### 2.3 Google 搜索模板


  ### Phase 3 — 招标信息结构化提取

  对每条找到的招标信息，提取以下结构化字段：

  | 字段 | 说明 | 提取方式 |
  |------|------|---------|
  | **招标编号** | 平台唯一编号 | 从公告原文提取 |
  | **招标标题** | 完整标题 | 原文 |
  | **采购方** | 采购单位名称 + 国家 | 原文 |
  | **产品/服务描述** | 简要说明采购内容 | 原文摘要 |
  | **预算金额** | 金额 + 币种 + 是否含税 | 原文 / [推断] |
  | **截止日期** | 投标截止时间（精确到日） | 原文（关键字段，必须标注） |
  | **开标日期** | 如有 | 原文 |
  | **资格要求** | 是否有特殊资质要求 | 原文摘要 |
  | **投标方式** | 线上/线下/电子竞标 | 原文 |
  | **保证金** | 投标保函/保证金金额 | 原文 |
  | **来源平台** | 发布平台名称 | ✅ |
  | **来源 URL** | 原始公告链接 | ✅ |
  | **发布日期** | 公告发布日期 | ✅ |
  | **匹配度** | 与用户产品的匹配程度 | [推断] 高/中/低 |

  ### Phase 4 — 投标机会评估

  从以下维度评估每条招标的投标价值：

  1. **匹配度评估**（高/中/低）：
     - 高：产品/服务描述与用户产品完全匹配，无强制资质障碍
     - 中：部分匹配，或需要额外认证/本地代理
     - 低：仅有部分组件匹配，或资质要求差距较大

  2. **紧迫性评分**（截至今天还剩几天）：
     - 🔴 紧急（≤7天）：需立即行动
     - 🟡 紧张（8-21天）：建议本周内决定
     - 🟢 充裕（22天+）：有充分准备时间

  3. **可行性提示**：
     - 是否需要当地代理/代表
     - 是否需要特定认证（CE/ISO/FDA 等）
     - 是否需要投标保函（银行手续需时间）
     - 是否要求过往业绩证明

# B2B 招标信息查询整理

## 概述

通过 web_search 从公开招标平台（dgMarket/UNGM/TED/ADB 等国际平台 + 国别平台）实时搜索、筛选、整理 B2B 招标信息，帮助外贸业务员发现并评估投标机会。所有信息必须标注来源 URL 和发布日期，禁止编造。

## 输入

- 产品/品类名称 + 目标国家/区域（可选）
- 预算范围 / 招标类型 / 截止时间（可选）
- 关键词语言（中英文各一套）

## 输出

- 招标信息汇总报告：招标编号/标题/采购方/预算/截止日期/资质要求/匹配度评估/可行性建议
- 每条含来源 URL + 发布日期 + [确切]/[推断] 标注
- 投标机会评估（高/中/低匹配度 + 紧迫性 + 可行性提示）
- 建议行动（优先跟进 / 关注备选 / 设置定期监控）
