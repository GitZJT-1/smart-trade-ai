# NLMK SRM 主 PDF（0.PDF）解析笔记

来源：某批 4 个钢厂 SRM 标段（20157101/0、20157105/0、20157145/0、20157168/0）整理实测（源为按天归档的邮件抓取结果目录，同事转发）。
**配套**：下游「整理 → 询价单生成」流程见 `b2b-tender-processing` skill；本文件是 0.PDF 的字段级解析笔记，两个 skill 共用。

## 1. 0.PDF 的固定信息块

| 字段（PDF 原文） | 含义 | 用途 |
|:--|:--|:--|
| `Номер конкурса` | 标段号（含 `/0` 版本） | 文件夹名、询价单文件名 |
| `Описание` | 采购内容概述 | 中文品名参考 |
| `Валюта конкурса` / `Дополнительные разрешенные валюты` | 主币种 + 可选币种 | 交付报告；本轮四标段均为 RUB，另允许 CNY / UEUSD / UEEUR / UECNY 的组合 |
| `Пеериод подачи` / `Дата открытия` | 提交截止（UTC+8） | 交付报告必写；本轮最紧的距收到仅一天 |
| `Примечание закупщика` | 采购方备注 | **投标成败条款**，见 §4 |
| `Приложения:` | 附件图号清单 | 核对附件数量（列几个图号 = 几个附件） |
| 行项表 `Поз./№ продукта/Название/Количество` | 行项 | 询价单主体，解析见 §2 |

页数不固定（本轮 1 / 4 / 2 / 1 页）；行项跨页时每页重复表头与 `Страница k / N`。

## 2. 行项表解析：文本顺序会错乱

`page.get_text()` 按列块拼接，阅读顺序 ≠ 语义顺序。三类实测畸变：

1. **序号 token 出现在上一行数量之后**：序列形如 `… 785764 Болт … 0037.110.41 / 10,000 ШТ / 2 Material …`，序号跟在上一行数量后面 → 「从 `ШТ` 往回找第一个纯数字 token 当行号」会整体错位一格。
2. **图号落到下一页顶部**：窄图号列被拆到页边界之外——20157105 的 Поз2 图号 `0037.077.41` 出现在第 2 页首行；Поз14 的 `466065 Кольцо уплотнительное 1012.100.62` 出现在第 3 页首行、位于 `15 Material` 之前。
3. **数量偶发粘到名称尾部**：列距过小时拼成一串，如 `696366 Шлангопровод 1078.361.411,000 ШТ`（= 名称 `…1078.361.41` + 数量 `1,000`）。按整 token 匹配 `^\d{1,3},\d{3}\s*ШТ$` 会**漏掉这一行**（本轮基于 token 的解析只拿到 31/32 行）。

### 可靠映射规则（唯一一条）

> 按文档顺序，**第 k 个 `N,NNN ШТ` token = SRM 第 k 号位**。

三项自查，全过才算核完：

- `ШТ` token 数 == `Material` token 数 == 询价单数据行数；
- 数量总量与常识不冲突（本轮 20157105 合计 101 件）；
- 用同标段一件大件反证**俄式数字（逗号=小数点）**：12 491 kg 的酸洗槽在 SRM 里是 `1,000 ШТ` → 1 件；误读成 1000 件时单件重量立刻荒谬。同理 `10,000 ШТ`=10 件、`4.800,000 ШТ`=4800 件。

20157105 实测数量序列（32 行，与序号 1..32 一一对应）：

```
10,10,3,1,3,1,1,2,2,2,2,3,1,2,2,3,3,1,1,1,1,2,1,1,2,2,2,1,18,10,6,1
```

## 3. 名称/物料号回填规则

- 「物料号」列 = `№ продукта`（如 1188216 / 447537 / 1193096 / 969440）。
- 「名称」列 = `Название`，**去掉 SRM 的 `&` 标记前缀**（`&Ванна травления В2/В3` → `Ванна травления В2/В3`），图号补进括号。
- `Название` 为空（20157145 第 2 项只有 `чертеж 80906-08.00.00СБ`）或只给图号时：**名称与翻译回图纸标题栏取**，交付报告注明名称来源。
- `Название` 尾部孤立的一个数字（20157105 поз32 `1112.701.63 1`）可能是件号的一部分，按可见部分落单并在报告提示向采购方核对。
- 交货期列显示 `00:00:00` = 该标段未给交货期（20157145、20157168）→ 不编日期，「交货期」留空并在报告写明；给了日期的（20157101 `10.04.2027`、20157105 `10.02.2027`）写进报告提醒排产。

## 4. Примечание закупщика 必摘条款（本轮实例）

- 付款：`оплата за полученное в течение 45-60 дней с даты поставки товара`（20157101，НЛМК 常用条件）。
- 要求：`прошу в конкурсе прописать площадку(место), где будут производиться детали` —— 投标书必须写明**加工地点**（20157101）。
- 要求：`не забывать указывать срок поставки, завод изготовитель/год, замечания оферента по позиционно`（20157168）。
- RFI 声明：`Данный конкурс является запросом цен для бюджета (RFI) … будут включены в пул поставщиков при будущей закупке`（20157145）→ **预算询价、不会直接定标**，报价方只是进入后续采购的供应商池；交付报告要显著标注，它决定这份报价投多少精力。
- 标准条款块（20157105）：投标须在 SAP SRM 系统内提交、推荐 RUB、非俄居民可用 UE 货币、`не являются торгами`（不受 ГК РФ 447-449 / 1057-1061 约束）。

## 5. 附件核对与无图纸件的填法

- `Приложения:` 列的图号数 == 进文件夹的编号附件数：20157101=1（图纸 PNG）、20157105=1（离心机护照 PDF）、20157145=3（2 个扫描 PDF + 1 个 400 dpi .tif）、20157168=0（只有 0.PDF）。
- 附件名常自带 НЛМК 工单号（`по 013-3323`、`013-3528`、`013-2584`），保留原文件名、只加数字前缀。
- **无图纸的外购件/标准件：单重与材质两列都填「按原厂标准」**——备件、外购设备（离心机备件、TECNA 焊机变压器）只有件号没零件图时，不按件名猜材质（`Кольцо уплотнительное` 不写「橡胶」），单重也不写「按图纸」。附件里的设备护照/铭牌是关键技术输入（`Паспорт центрифуг` → Flottweg DECANTER Z4E-4/441, SP 3.10），机型与件号体系要写进交付报告。
- **GOST 标题栏有 `Масса`、通常没有材质栏**：标题栏 `Масса` 即权威单重（如 12491 / 10190 / 7152 kg）；材质缺失写「按图纸」，可依技术要求行补注依据（`焊材 Св-08Г2С ГОСТ 2246-70` → 碳钢结构），报告注明「请厂家按图纸材料表核定」，不得直接断言钢号。
