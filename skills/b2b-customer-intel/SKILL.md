  - **区分"已知"和"推测"**。已知事实标为 [确切]，从公开信息推断的标为 [推断]，猜测的标为 [待确认]。

  ## 15 维度画像结构

  ### 1. 基础身份
  - 公司全称、公司规模（员工数/年营业额）、行业地位
  - 客户姓名、职位、在公司的决策权重（最终决策者 / 推荐者 / 影响者）
  - 上级汇报关系（向谁汇报？他上面还有谁？）
  - 在公司的工作年限（老员工还是新入职？）
  - 来源：[确切] [推断] [待确认]

  ### 2. 家庭与个人背景
  - 婚姻状况、配偶姓名
  - 子女（数量、名字、年龄、学校/工作）
  - 宠物（品种、名字）
  - 重要纪念日：结婚纪念日、子女生日、入职周年
  - 个人爱好：运动/音乐/阅读/旅行/美食/酒类偏好
  - 教育背景：毕业院校、专业
  - 前雇主/行业经验
  - 宗教信仰（涉及饮食禁忌/节日/礼俗）
  - [待确认] 字段越多越好——这些都是建立私人关系的切入点

  ### 3. 性格与决策风格
  - 性格类型：直接型 / 分析型 / 关系型 / 社交型
  - 决策速度：快（当场拍板）/ 中（需要思考）/ 慢（多层审批）
  - 风险偏好：冒险者 / 稳健派 / 极度保守
  - 对新供应商的态度：开放 / 谨慎 / 完全不想换
  - 压力下的反应：冷静 / 急躁 / 拖延
  - 被什么打动：数据 / 案例 / 关系 / 价格 / 品质 / 交期

  ### 4. 沟通偏好
  - 首选渠道：Email / WhatsApp / LinkedIn / WeChat / Phone / In-person
  - 最佳联系时间（当地时间和北京时间）
  - 联系频率偏好：每周 / 双周 / 每月 / 仅有事时
  - 语言偏好：English / 中文 / 西班牙语 / ...
  - 语气偏好：Professional / Casual / Warm / Direct
  - 称呼偏好：Hi John / Dear Mr. Smith / John-san
  - **交流禁忌**：
    - 不喜欢被催促
    - 不要提竞品
    - 不要在周末发消息
    - 不要群发式称呼
    - 不要用过于亲昵的语言

  ### 5. 采购与需求画像
  - 采购的产品类别和规格
  - 年预估采购量和采购频率
  - 采购旺季时段
  - 预算区间（单笔预算 / 年度预算）
  - 当前供应商和合作时长——找替换机会的窗口
  - 对现有供应商的满意度——哪里不满意
  - MOQ 接受程度
  - 品质标准（AQL 等级 / 认证要求）
  - 验货要求：第三方 SGS/BV / 自己来厂 / 寄样确认
  - 🔒 来源：[确切] [推断]

  ### 6. 报价与定价策略
  - 价格敏感度：高（纯价格导向）/ 中（性价比导向）/ 低（品质导向）
  - 谈判风格：直接砍价型 / 沉默施压型 / 比较三家型 / 专业询价型
  - 报价应对策略：
    - 首轮报价留多少谈判空间
    - 让步优先级：先让交期 > 再让付款条件 > 最后动价格
    - 底线价格
  - 成交价格历史记录
  - 🔒 价格底线和报价策略属敏感信息

  ### 7. 付款与信用
  - 常用付款方式：TT / L/C / D/P / OA
  - 首付比例偏好
  - 付款准时度：准时 / 偶尔延迟 / 频繁延迟
  - 信用额度和赊销记录
  - 银行信息（如有）
  - 🔒 信用记录属敏感信息

  ### 8. 佣金与回扣
  - 客户是否要求回扣 / 佣金
  - 回扣比例和计算方式
  - 支付方式（是否通过香港/海外账户）
  - 客户是否暗示过"可以从供应商那里拿好处"
  - 🔒 公司回扣政策：允许 / 禁止 / 需审批
  - 历史回扣记录和金额
  - 🔒 整个维度为最高敏感级别

  ### 9. 送礼与商务礼仪
  - **送礼记录**：
    - 日期 / 节日 / 礼品 / 价值 / 客户反应
    - 客户偏好礼品类型（茶叶 / 电子产品 / 酒 / 工艺品）
  - **送礼预算**：单次预算上限
  - **送礼禁忌**：
    - 不能送钟（中国客户）——谐音"送终"
    - 不能送酒（伊斯兰客户）
    - 不能送皮革（印度教客户）
    - 不能送太贵重的（欧洲客户有合规要求）
    - 某些公司有严格的反贿赂政策（如美国 FCPA 适用公司）
  - **商务宴请偏好**：餐厅类型 / 是否饮酒 / 谁买单 / AA

  ### 10. 信任建立与关系阶段
  - 当前关系阶段：新接触 / 尝试合作 / 稳定合作 / 战略伙伴 / 休眠
  - 首次合作时间
  - 累计交易金额
  - 信任指数（1-5）：是否信任你的报价 / 是否信任你的交期 / 是否推荐过朋友
  - **信任建立的里程碑**：
    - 第一次报价成功
    - 第一次样品确认
    - 第一次大单
    - 第一次他主动联系你
    - 第一次给你介绍客户

  ### 11. 痛点与动机
  - 核心业务痛点（至少 3 个）：
    - 交期不稳定？品质波动？认证不全？供应商管理太累？利润太薄？
  - 个人职业动机：
    - 想升职？想跳槽？想创业？想在老板面前表现？想安全度过试用期？
  - **恐惧和担忧**：
    - 丢工作——换了供应商出问题他得负责
    - 丢客户——终端客户对他的交付不满意
    - 被老板骂——采购成本超支
  - 对他而言"成功"是什么？

  ### 12. 购买信号与行为模式
  - 当他说什么的时候代表快成交了：
    - 「给我发一份 PI」→ 走流程了
    - 「你们能做信用证吗」→ 担心风险但在认真考虑
    - 「跟老板/合伙人商量一下」→ 自己有决定权但需要一个台阶
    - 「我问一下运费」→ 在算总成本了
  - 当他说什么的时候代表不会买了：
    - 「我再考虑一下」→ 大概率不会考虑
    - 「你们的报价比别的供应商高太多」→ 价格导向，没有做进去的价值
    - 邮件越来越短 → 失去兴趣
  - 回邮件的时间模式：什么时候回得最快 / 什么时候一周不回

  ### 13. 竞品关系
  - 已知的竞争对手供应商
  - 他的其他供应商名单和价格区间
  - 他比较供应商的方式（比价表格 / 打样对比 / 口头比较）
  - 我们对比竞品的优势和劣势
  - 🔒 竞品信息标注来源

  ### 14. 文化与地域适配
  - 目标国家/地区的商业文化特点
  - 该国家/地区常见的商务谈判习惯
  - 当地假期和斋月时间（影响沟通和付款）
  - 礼节性问候语（阿拉伯语、西班牙语等）

  ### 15. 风险与红旗
  - 信用风险：是否有过付款拖欠 / 无理由拒付 / 索赔记录
  - 合规风险：是否在制裁名单所在国家经营 / 是否要求提供虚假单证
  - 法律风险：是否有过合同纠纷 / 是否在仲裁中
  - 商业风险：是否过度依赖单一客户 / 是否在衰退期行业
  - 🔒 整个维度为敏感信息

  ## 工作流程

  ### Phase 1 — 信息收集
  用户提供客户的任何已知信息（公司名、LinkedIn链接、对话记录片段、展会名片、WhatsApp截图等），你按 15 维度逐一分析：

  - 从已知信息中提取确定事实 → 标 [确切]
  - 基于公开信息推断 → 标 [推断]
  - 未知但重要的 → 标 [待确认]，并给出**具体建议**（如"下次聊天时顺带问问他的度假计划"）

  ### Phase 2 — 对话补全
  当用户提供与该客户的聊天记录或对话要点时：
  1. 识别对话中提到的新信息
  2. 更新对应维度
  3. 标记哪些[待确认]变成了[确切]
  4. 指出还有哪些关键维度缺失，建议下次交流时可以问什么

  ### Phase 3 — 画像查询
  用户说「查一下 XX 客户的画像」时：
  1. 从数据库（customers.extra3）读取已存储的画像
  2. 按 15 维度格式化展示
  3. 标出**最关键的 3 个行动建议**（如"下周是他结婚纪念日，建议发个祝福消息"）

  ### Phase 4 — 谈判/沟通前的快速简报
  用户说「我要跟 XX 客户谈价格」或「我要给 XX 打电话了」时：
  1. 调取画像中与本次沟通最相关的 3-5 条信息
  2. 给出一句话建议：这次沟通的目标是什么、怎么开场、要注意什么
  3. 如果即将触发重要日期（生日、节日），提醒用户

  ## 输出格式

  ```
  ## 📋 [客户姓名] — 深度画像

  ### 🏷️ 基础身份
  [确切/推断/待确认结构]

  ### 👨‍👩‍👧 家庭与个人
  ...

  [15 个维度逐项列出]

  ## ⚡ 三件现在该做的事
  1. [最重要]
  2. [次要]
  3. [提醒]

  ## 📝 信息来源
  [每条信息的来源标注]
  ```

  **语言规则**：画像内容用中文（用户内部使用）。需要发给客户的内容用目标语言。

# B2B Customer Intelligence — 单一客户深度画像

## 概述

为单一客户建立 15 维度的全方位情报档案，覆盖从基本信息到谈判策略、送礼禁忌、家庭背景、风险红旗的全部维度。画像以 JSON 格式存储在 `customers.extra3` 字段中，支持渐进式补全。

## 输入

- 客户的任何已知信息：公司名、LinkedIn链接、名片、聊天记录、展会见面记录
- 或：查询已有客户的深度画像

## 输出

- 15 维度的结构化画像报告
- 信息来源标注（确切/推断/待确认）
- 3 件现在该做的事（行动建议）
- 画像自动写入 customers.extra3
