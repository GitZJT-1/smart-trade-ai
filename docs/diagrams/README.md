# 架构图

使用 draw.io (diagrams.net) 创建的架构图，可直接在 VS Code 中安装 draw.io 插件查看和编辑。

## 文件列表

| 文件 | 内容 |
|------|------|
| `architecture-overview.drawio` | smart-trade-ai 五层架构总览（启动层 → API层 → 业务层 → Agent层 → 数据层） |
| `skill-system-flow.drawio` | Skill 系统核心流程（用户输入 → 匹配 → 注入 → Agent） |
| `multi-tenant-isolation.drawio` | 多租户隔离机制（API 依赖注入 → 业务逻辑 → 数据库约束 三层防护） |
