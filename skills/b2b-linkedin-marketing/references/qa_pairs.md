# b2b-linkedin-marketing 结构化 QA 知识库

> 来源：大宗师培训资料  
> 用途：Agent 精准检索注入，每条独立自洽

## Q1: LinkedIn 个人主页应该怎么打造？
**答案**: 7天计划：Day1头像(400x400不能是LOGO/合照)+Banner(1584x396)+个性化URL → Day2 Headline(产品词+角色+价值≤150字符)+About(Who we are→What we make→Who we serve→Strengths≤800字符，五种架构：3W+1H/Dream+Help/Story+Specialties/数据+案例/Pain Point) → Day3 Experience(公司20条优势→价值展示非罗列职责→嵌入关键词)+Skills(10-15个英文关键词) → Day4 Featured富媒体+Media(Title≤60字符/Description≤500字符) → Day5推荐信(至少3封，先给别人写) → Day6 Contact Info+证书背书 → Day7隐私检查(联系人仅自己可见/动态关闭公开/Groups隐私/无痕浏览器模拟买家视角)。
**标签**: 主页打造
**场景**: 新建或优化LinkedIn个人主页
**关键词**: 7天计划, Headline, About, Experience, 隐私设置

## Q2: LinkedIn 五维度内容营销是什么？
**答案**: ①Post-视频(产品展示/工厂参观/客户案例)②Post-照片(工程现场/装箱发货/团队)③Post-文章(行业深度长文，SEO权重高，长尾词可排谷歌首页)④投票(高参与度/轻互动/引导评论)⑤Document(上传高价值资料如产品目录/选型指南，引导客户下载获取线索)。三支柱内容配比：技术40%+项目30%+动态30%。发布节奏：周二/四/六。全年月度主题线+季度市场重点。
**标签**: 内容矩阵
**场景**: 制定LinkedIn内容计划
**关键词**: 五维度, 三支柱, Post, Document, 发布节奏

## Q3: 怎么用LinkedIn精准开发客户？
**答案**: 三步闭环：①画像素级客户画像(仅需主营产品→输出目标市场/行业分类/搜索关键词/客户类型/公司规模/决策人职位6大维度)②Sales Navigator精准搜索(布尔运算符：职位OR产品关键词OR行业AND国家AND公司规模11-200人)③Add Note 300字符开发(人维度/公司维度两套模板，引用买家背景关键词+产品匹配点，专业真诚不推销)。原则：关注→有post就评论→忍不住想开发才用Add Note。哪怕没post也一定关注(关注后LinkedIn算法更懂你)。
**标签**: 客户开发
**场景**: 主动开发LinkedIn客户
**关键词**: 客户画像, Sales Navigator, Add Note, 布尔搜索

## Q4: Add Note 怎么写回复率最高？
**答案**: ≤300字符。人维度模板(针对个人)：引用Ta近期post/公司背景+1句产品匹配+专业真诚不推销。公司维度模板(针对公司页面)：称赞公司+提行业共鸣+暗示合作可能。关键：不是推销，是"我注意到了你们在XX领域的成就，我们正好是XX领域的中国供应商"。先发Connection Request而非InMail，按后台数据(是否看过视频/案例/分享)决定后续跟进话术。禁止：群发/模板化/上来就报价。
**标签**: Add Note
**场景**: 加LinkedIn好友时
**关键词**: Add Note, 300字符, 人维度, 公司维度, Connection Request

## Q5: Smart Link 怎么用？
**答案**: 三步精准投递：①画客户画像②Sales Navigator搜索③针对单一客户定制Smart Link(命名带对方公司名、打包3个文件：本地气候应对PDF+安装视频+成功案例)。按后台数据(看了视频/案例/分享)决定跟进话术——看了视频=对产品感兴趣，看了案例=在评估供应商，分享了=有决策权正在对比。不要群发同一个Smart Link给所有客户。
**标签**: Smart Link
**场景**: 深度跟进目标客户
**关键词**: Smart Link, 定制, 后台数据, 视频, 案例

## Q6: LinkedIn 安全规则有哪些？
**答案**: ①一天加好友不超100个②新号先内部互加50人再开发③绝对不加国内同行(防举报封号)④界面语言切英文(功能更全)⑤高级会员专属：Spy竞品公司员工列表/TeamLink突破二度人脉/Lead Builder保存搜索模板/竞争对手动态监控/InMail直触⑥公司主页：About us含产品关键词和工厂优势，公司规模/成立年份/认证/主要市场全部填写⑦用Google Site Search扩展搜索：site:linkedin.com "职位" "行业" "国家"。
**标签**: 安全规则
**场景**: 日常LinkedIn运营
**关键词**: 加好友上限, 防封号, 高级会员, 英文界面

## Q7: LinkedIn 领英主页SEO怎么优化？
**答案**: Headline含产品关键词+角色+价值(≤150字符)。About含SEO关键词(产品词/行业词/长尾词)，用分段式排版让买家不累。Skills前3位放产品关键词。Experience自然融入关键词+链接公司主页。Media标题带关键词。个性化URL用姓名+行业词利于SEO。多语言档案(英语+西语覆盖拉美市场)。
**标签**: SEO优化
**场景**: 优化LinkedIn个人主页搜索排名
**关键词**: Headline关键词, Skills, URL, 多语言, 长尾词

## Q8: LinkedIn 公司主页怎么运营？
**答案**: About us含产品关键词和工厂优势。公司规模/成立年份/认证/主要市场全部填写(不填=不专业)。每周三发布一篇公司级别Post。Document引流：上传高价值资料(产品目录/选型指南/行业白皮书)，标题带产品关键词，Description引导目标客户下载。关注竞品公司主页→看他们的员工列表→这些人就是你的潜在客户。
**标签**: 公司主页
**场景**: 运营LinkedIn公司页面
**关键词**: About us, 公司主页, Document引流, 每周三, 竞品关注
