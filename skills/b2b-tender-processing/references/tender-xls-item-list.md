# 招标清单提取 — tenderXXXXXX.xls 第二工作表（Список позиций）

2026-08-05 实测：ISO 三分部自动化车间集采（1223588，109 项）与 ISO 布拉茨克铸造生产零件（1224579，702 项）两个标段。

## 文件结构（tenderXXXXXX.xls）

- 旧版 BIFF .xls → 必须 xlrd 读取（pandas 读 .xls 同样依赖 xlrd，直接用 xlrd 更轻）
- **第二张工作表（`sheet_by_index(1)`）是 «Список позиций»（清单）**：
  - r0：标题 «Список позиций для процедуры № XXXX»
  - r2：`НДС 22.0` + 备注 «Цены указываются без НДС»（价格不含 22% 增值税）
  - r4：表头 `№ | Наименование | Комментарий | Кол-во | Ед.изм. | Макс.цена | Предложение за 1 ед.изм. | Наименование Аналога`
  - r5 起：数据行
- **工作表名不可靠**：1224579 的 sheet 名是 `Sheet3`（Sheet2 被删），1223588 是 `Sheet2` → **必须按索引 1 取，禁止按名字找**
- 数量列 = col 3，单位列 = col 4（ШТ / шт，俄语「件」）
- 空行判定：№ 与 Наименование 皆空则跳过

## 致命坑：rstrip(".0") 截断数字

`'700.0'.rstrip('.0')` → `'7'`（rstrip 按**字符集**逐个剥除，不是剥子串）！
同类事故：`'10.0'` → `'1'`、`'100.0'` → `'1'`、`'20.0'` → `'2'`。
**数字列严禁 rstrip 清洗**。正确做法：

```python
def num2str(v):
    if v in ("", None):
        return ""
    if isinstance(v, float):
        return str(int(v)) if v == int(v) else str(v)
    s = str(v).strip()
    try:
        f = float(s)
        return str(int(f)) if f == int(f) else s
    except ValueError:
        return s
```

## 提取脚本骨架

```python
import xlrd, json

wb = xlrd.open_workbook(path)
sh = wb.sheet_by_index(1)  # 第二张工作表，不要按 sheet 名
rows = []
for r in range(5, sh.nrows):  # r4 是表头
    no, name = sh.cell_value(r, 0), sh.cell_value(r, 1)
    qty, unit = sh.cell_value(r, 3), sh.cell_value(r, 4)
    if not num2str(no) and not num2str(name):
        continue
    rows.append({"№": num2str(no), "Наименование": num2str(name),
                 "Кол-во": num2str(qty), "Ед.изм.": num2str(unit)})
# 落盘 utf-8 + ensure_ascii=False
```

- 断言条目数 == 表头预期

- 断言字段集合 == `{"№","Наименование","Кол-во","Ед.изм."}` 且名称非空

## .xlsx 变体（Приложение №1 2027，2026-08-05 实测 1224501，1254 项）

- 文件是 **xlsx**（非 BIFF .xls）→ 用 **openpyxl** 读（data_only=True），不是 xlrd
- **单工作表**（`Лист1`），行结构（0 索引）：
  - r0：标题 `Приложение №1 к запросу №____`；r3：`Номенклатура и потребность...`
  - r5：表头 `№ п/п | Код SAP | Наименование ТМЦ | Филиал | Узел сопрягаемости | Ед.изм. | Количество на 2027... | Кол-во итого | Стоимость, руб/шт без НДС`
  - r6：月份子表头（январь..декабрь，12 列）
  - **r7 起数据**（excel row 8 起）
- 列索引（1 起）：A=№, B=Код SAP, C=Наименование, D=Филиал, E=Узел, F=Ед.изм., G..R=1-12月数量, S=Кол-во итого, T=Стоимость руб/шт
- **表尾签名行坑**：末行 A 列是 `Начальник отдела`（负责人签字）混入数据 → 用 `not no_s.isdigit(): continue` 过滤，只留数字序号行
- **小数数量坑**：米制件（Ед.изм.=М）数量为小数（57.984），openpyxl 读出 `57.983999999999995` 浮点噪音 → `round(float, 3)` 清洗；求和用 float 精确和（整数 isdigit 求和会把小数行漏掉）
- 验证：序号连续 1..N、月度求和==总计列（1254 条全部一致）、Филиал 分布（БФ/КФ/НФ/СФ/ТФ/ШФ 六分部）、单价列全空=报价模板待填属正常
- 输出结构比 .xls 版多保留：Код SAP、Филиал、Узел、月度明细（12 键）、Стоимость 列
