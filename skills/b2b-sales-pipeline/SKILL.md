  ## 场景路由

  ### Phase 1 — 客户推进策略（提供客户当前阶段）
  用户告知客户当前状态（如"刚发开发信没回"、"寄了样品"、"在谈价格"），你输出：

  1. **客户当前阶段判定** — 按 5 阶段模型：
     - **Awareness**：客户刚接触你、不知道你能做什么
     - **Interest**：客户回复了、表现兴趣
     - **Consideration**：客户在看报价/样品、在比较
     - **Decision**：客户快定了、在谈具体条款
     - **Retention**：已成交、保持关系、争取复购

  2. **阶段销售动作**：
     - 当前状态 → 推荐动作 → 推进目标
     - 动作模板（开发信 / InMail / 视频会议邀请 / 寄样跟进 / 报价跟进 / 条款确认）

  3. **下一步建议**：如果此动作未收到回应，下一个动作是什么

  ### Phase 2 — 完整管线策略（提供产品 + 客户类型）
  用户直接说"帮我设计一个客户跟进计划"，你按以下输出：

  1. **5 阶段客户旅程映射表**
  2. **30 天跟进时间表**（Day 1→30 的逐日行动）
  3. **KPI 目标参考值**
  4. **客户状态分层与各层策略**

  ### Phase 3 — 销售数据诊断（提供客户列表+当前状态）
  用户提供一个客户名单和各自状态，你输出：

  1. **管线健康度评估**：各阶段客户数分布、风险信号
  2. **每天最小可行动作**（每个客户本周最重要的 1 个动作）
  3. **优先顺序建议**：哪些客户最紧迫、哪些可以降级

    ### Phase 4 — 价格谈判策略
  当用户需要进行价格谈判时，提供 5 个谈判筹码维度，帮助用户在不单纯降价的情况下推进交易：

  1. **数量杠杆**：分档定价（100pcs/500pcs/1000pcs），用小订单建立信任后再推新品
  2. **付款条件杠杆**：不同首付比例对应不同价格（TT 30%=15USD, 50%=14.5USD, 70%=14USD），付款越早价格越低
  3. **交期杠杆**：利用交期作为让步条件（标准交期=标准价，加急/弹性交期可调整价格）
  4. **材料替代杠杆**：在功能和品质不受影响的前提下用替代材料降低报价（如铝型材换PC塑料）
  5. **折扣类型杠杆**：区分数量折扣/年度折扣/代理折扣/季节性折扣/佣金折扣

  给用户一个谈判筹码清单，让其在谈判中有策略地逐步释放，而不是一次性给出最低价。

# B2B Sales Pipeline — 销售管线策略

## 概述

系统化设计 B2B 客户推进策略，覆盖从初次接触到成交到复购的全流程动作规划。

## 输入

- 客户当前状态（已发开发信/已寄样/在谈价格等）
- 或：产品信息 + 目标客户类型（用于 30 天完整计划）
- 或：客户名单 + 各客户当前状态（用于诊断）

## 输出

- 5 阶段客户旅程映射
- 阶段销售动作模板
- 30 天跟进时间表
- KPI 目标参考值
- 客户状态分层与各层策略
- 管线健康度评估

## 与相关 Skill 的分工

- `b2b-customer-mgmt`：管客户档案和 CRUD
- `b2b-cold-outreach`：管开发信邮件撰写
- `b2b-sales-pipeline`：**管推进动作规划和策略**，跨越从接触到成交的完整旅程
