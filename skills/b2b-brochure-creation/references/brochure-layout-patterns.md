# 企业宣传册 / 产品目录 — 版面设计模式

## 参考案例：沈阳百欧通用机械有限公司矿山行业宣传册

- **公司**：沈阳百欧通用机械有限公司（byogm.com）
- **行业**：矿山设备制造
- **语言**：中英双语
- **页数**：10页（封面 + 8内页 + 封底）
- **输出格式**：单文件 HTML（可打印/导出PDF）
- **配图**：16张（5产品 + 6设备 + 3认证 + 2产品细节），全部来自官网

## 封面设计模板（改进版：带实景产品图）

```html
.cover {
  background: linear-gradient(135deg, #0f2027 0%, #203a43 40%, #2c5364 100%);
  color: #fff;
  display: flex;
  flex-direction: row;  /* 左右布局，左侧内容区 + 右侧产品图 */
  align-items: center;
  justify-content: center;
  min-height: 210mm;    /* 横版高度 */
}
.cover .content { flex: 1; text-align: center; padding: 0 50px; }
.cover .side-graphic {
  width: 320px; height: 210mm; overflow: hidden;
  display: flex; align-items: center; justify-content: center;
}
.cover .side-graphic img {
  width: 100%; height: 100%; object-fit: cover;
  opacity: 0.35; /* 半透明叠底，不影响文字可读性 */
}
.cover h1 { font-size: 48px; font-weight: 900; letter-spacing: 8px; }
.cover .tagline { font-size: 22px; color: #e8c44a; margin: 20px 0 8px; }
.cover .gold-bar { width: 100px; height: 4px; background: #e8c44a; margin: 16px auto; }

/* 封底复用同样模式，左侧产品图，右侧联系信息 */
.back-cover {
  background: linear-gradient(135deg, #2c5364 0%, #203a43 50%, #0f2027 100%);
  color: #fff; display: flex; flex-direction: row;
}
.back-cover .deco-section { width: 260px; height: 210mm; }
.back-cover .deco-section img { opacity: 0.25; object-fit: cover; }
```

## 页面填充技巧（消除空白）

当页面内容不足以填满210mm高度时，用以下元素填充：

| 填充工具 | 适用页面 | 示例 |
|:---------|:---------|:-----|
| 数据条 Data-bar | 概览/检测页 | 5列数据卡片（45,000㎡ / 300+员工 / 25%工... |
| 功能标签行 Feature-strip | 产品/详情页 | 5个标签（铸造 / 热处理 / 机加工 / 装配 / 质检） |
| 参数卡片行 Product-spec | 产品页底部 | 6列产品参数（处理量/进料/效率...） |
| 实景图片条 | 伙伴页底部 | 3张55px产品/设备缩略图横排 |
| 应用场景网格 App-grid | 产品详情页 | 2x2网格列出典型项目案例 |
| 服务网格 Service-grid | 服务流程页 | 2x3网格列出6项售后服务承诺 |

## 迭代交付节奏

实际项目中几乎不可能一次到位。推荐以下交付节奏：

```
V1:   内容骨架 + 版面结构       → 确认信息完整性
V2:   嵌入首批真实图片          → 确认图片合适
V3:   根据反馈调整方向/布局      → 横版/竖版、密度、配图比例
V4:   替换所有SVG占位符         → 全部使用真实照片
V5+:  填充空白、优化排版         → 每页饱满，无空白
```

每个版本都保存为新文件（V1/V2/V3/V4/V5），方便用户对比回溯。
