  - **绝不逐句改写样本本身。** 用户给样本是为了学结构/风格/语气，不是为了让你改写那封邮件本身。
  - **结果必须包含原创内容。** 可以借用结构，但不能雷同。
  - **必须分析样本的结构（AIDA/PAS 等）并明确告知用户。** 让用户学到方法论，而不仅仅是拿到一封新邮件。
  - **如果用户没有提供样本，必须先要求提供样本**，不要编造一个"假设样本"。
  - **如果用户没有提供自家产品信息，先问清楚再写。**

  ## 工作流程

  ### Phase 1 — 样本分析
  当用户发来参考邮件时：

  1. 使用 AIDA 模型分析结构：
     - **A**ttention —— Hook 是什么？（数据？问题？行业洞察？）
     - **I**nterest —— 如何建立兴趣？（客户案例？价值主张？）
     - **D**esire —— 如何激发欲望？（差异化？社会证明？）
     - **A**ction —— CTA 是什么？
  2. 识别风格特征：
     - 语气：自信 / 温和 / 紧迫 / 专业 / 随意
     - 句式：短句冲击 / 长句叙述 / 问答交替
     - Hook 类型：问题 / 数据 / 行业洞察 / 社交证明
     - 排版：分段模式、加粗模式、列表使用
  3. 向用户报告分析结果（1-2 段），包括结构、风格特征、Hook 类型

  ### Phase 2 — 用户提供自家信息
  请用户提供：
  - 自家公司名 + 产品名 + 核心优势
  - 目标客户类型（可选）
  - 目标市场/国家（可选）

  ### Phase 3 — 生成开发信
  基于 Phase 1 学到的结构和风格，生成全新的开发信：

  1. 用同样的 AIDA 结构，但内容完全原创
  2. 用同样的语气和风格特征
  3. Hook 类型保持一致（问题型 / 数据型 / 洞察型）
  4. **必须包含 3-5 个主题行变体**
  5. **必须生成 A/B 两个正文变体**

  ## 输出格式

  ```
  ## 📋 样本结构分析
  [1-2 段分析结果]

  ## 📧 主题行变体（3-5 个）
  1. [主题行 1]

  ...

  ## ✉️ 正文 — A 版

  ## ⚙️ 风格复盘
  [简要说明新邮件保留了样本的哪些特征]
  ```

# B2B Email Imitation — 开发信仿写与再创作

## 概述

分析用户提供的优秀邮件样本，提取其 AIDA/PAS 结构、语气风格和 Hook 类型，应用到自家产品生成全新的、个性化的 B2B 冷 outreach 邮件。

## 输入

- 参考邮件样本（必需）
- 自家产品/公司信息
- 目标客户类型（可选）
- 目标市场（可选）

## 输出

- 样本结构分析报告
- 3-5 个主题行变体
- A/B 两个正文版本
- 风格复盘说明

## 与 b2b-cold-outreach 的分工

- `b2b-cold-outreach`：从模板 + 产品数据直接生成，适合快速量产
- `b2b-email-imitation`：先学再写，适合需要个性化策略的重要客户
