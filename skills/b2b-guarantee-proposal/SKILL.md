# B2B 商业提案生成器

## 概述

为 B2B 客户生成专业战略建议书/商业提案，支持多档位对比和 ROI 分析。

## 核心架构

多 Agent 协作模式：
1. 情报收集 Agent — 搜集行业/市场/竞品数据
2. 客户调研 Agent — 分析客户现状和痛点
3. 方案架构 Agent — 设计三档方案
4. ROI 分析 Agent — 投入产出计算
5. 质量控制 Agent — 独立审计，评分≥75分方可通过

## 输入

- 客户信息（公司/产品/市场/规模）
- 行业白皮书或市场数据
- 预算范围或档位偏好

## 输出

- 三档方案对比表
- 推荐方案详细说明书
- ROI 分析报告
- 实施路线图
- HTML 格式战略建议书（可选）
