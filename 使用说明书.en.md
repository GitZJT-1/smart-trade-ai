# Smart Trade AI — User Manual

An AI assistant for foreign trade — from finding customers to closing deals.

---

## 1. Installation

### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/chefroger/smart-trade-ai/main/scripts/install.sh | bash
```

### Windows

```powershell
powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/chefroger/smart-trade-ai/main/scripts/install.ps1' -OutFile install.ps1; .\install.ps1"
```

### Startup

```bash
python server.py
# Open browser at http://127.0.0.1:9119/trade
```

The first time you start, you need to configure the LLM API Key (in Hermes settings).

## 2. Interface Overview

The interface has a dark sidebar on the left (company selector, dashboard, lead gen, sales conversion, tools, history) and a light main content area on the right (chat, customer tables, task panel, history — switches based on what you click).

---

## 3. First-Time Use

### Creating a Company

Click the **+** button next to the company selector at the top of the sidebar, fill in company info, click "Create Company."

A folder named after your company will appear on the desktop, with subfolders for quotes, contracts, client profiles, product specs, invoices, shipping docs, certifications, marketing materials, and customs data. Put files in there and the AI can read them.

### Configuring Agent Identity

After creating a company, the popup shows an "Agent Identity" tab. Fill in what your company sells, your competitive edge, which markets you target, and your communication style. This shapes how the AI talks to you.

---

## 4. Feature Details

### Dashboard

Opening Trade lands you on the dashboard. It shows your scheduled task status (completed, pending, overdue) and recent conversations. Say "good morning briefing" and the AI generates the day's FX rates, commodity prices, market news, and client follow-ups.

### Lead Generation

**Customer Development** — Paste a LinkedIn link or some client info. The AI analyzes the background, writes a cold email, and gives you a follow-up plan (Day 1, Day 3, Day 7).

**Website Diagnosis** — Paste a product page link from Alibaba, Made-in-China, or your own site. The AI opens the page and gives you feedback on SEO, tech stack, and design.

**Social Media Marketing** — Tell the AI which platforms you use (Facebook, Instagram, TikTok, YouTube). It generates a content calendar with post copy you can use directly.

**LinkedIn** — Profile optimization, company page content strategy, InMail templates.

**Customs Data** — Drop CSV or Excel files into your desktop customs data folder. The AI finds high-value buyers, analyzes their purchasing patterns, and ranks them for you.

### Sales Conversion

**Customer Management** — A table view with name, rating, country, contact info, linked document libraries, and last follow-up time. A/B/C tier system. Click any row to open a detail panel on the right for editing info, managing libraries, or viewing recent conversations.

**Document Libraries** — Auto-linked to your desktop working directory folders. Select a library, then ask questions — AI reads the files and answers. Supports PDF, Word, Excel, PPT, images, CSV, and more. You can add other local directories too.

**Document Generation** — Tell the AI what you need (PPT presentation, Word contract, Excel quote). It generates the file for you to download.

### Tools

**Background Check** — Enter an email, domain, or company name. The AI cross-checks email platform registrations, WHOIS data, corporate email verification, sanctions lists, tech stack, and LinkedIn. You get a risk rating and recommendations.

**Scheduled Tasks** — The upper section has task templates (check what you want, set the time, write the prompt, hit "Batch Generate"). The lower section shows your active tasks — you can run any of them manually too. The daily morning briefing is on by default.

### Conversation History

All chats are stored in reverse chronological order. Search through them, click to jump back into context, or delete what you don't need anymore.

## 5. Common Operations

### Asking Questions

Just ask normally. Say "run a background check on ABC Company" — the AI figures out what to do. If you want to use files, put them in the desktop working directory first. You can also be specific, like "use b2b-osint to check this company."

### Viewing the Task List

Type "show task list" or "task list" or "today's tasks" in the chat box. The system will display the completion status of all scheduled tasks.

### Switching Companies

Use the dropdown at the top of the sidebar to select a company. All data (customers/document libraries/conversations) is isolated by company.

## 6. Data Storage

All data is stored locally and not uploaded to any server (except for LLM API calls):

| Data | Location |
|------|----------|
| Database | `~/.trade/data/trade.db` |
| Company profiles | `~/.trade/companies/{Company Name}/` |
| Desktop working directory | `~/Desktop/{Company Name}/` |
| LLM configuration | `~/.hermes/config.yaml` |
| API Key | `~/.hermes/.env` |

## 7. Frequently Asked Questions

**Q: How do I change the AI model?**
Run `hermes setup` to reconfigure.

**Q: How do I back up data?**
Simply copy the `~/.trade/` directory and the desktop working directory.

**Q: What formats does the AI support for document analysis?**
PDF, Word (.docx/.doc), Excel (.xlsx/.xls), PPT (.pptx/.ppt), CSV, images (.jpg/.png), Markdown, HTML, plain text.

**Q: Scheduled tasks are not executing?**
Make sure the Gateway is running (Trade will auto-start it on launch).

---

## 8. Security Notes

This tool runs with AI able to use system tools directly (no step-by-step approval prompts), since trade salespeople generally can't judge whether each instruction is safe. So: only use this locally or on a private network, don't expose it to the internet, keep your API key safe, and back up your data regularly.
