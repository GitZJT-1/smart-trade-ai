## 获取直链的方法

### 方法一：从缩略URL构造

```
缩略URL: https://upload.wikimedia.org/wikipedia/commons/thumb/7/75/UG_jaw_crusher.jpg/960px-UG_jaw_crusher.jpg
直链:    https://upload.wikimedia.org/wikipedia/commons/7/75/UG_jaw_crusher.jpg
去掉 /thumb/ 和 /960px- 即可
```

### 方法二：MediaWiki API（推荐）

```bash
curl -s -x http://127.0.0.1:7897 \
  "https://commons.wikimedia.org/w/api.php?action=query&titles=File:FILENAME.jpg&prop=imageinfo&iiprop=url&format=json" \
  -H "User-Agent: Mozilla/5.0" | python -c "
import sys, json; d = json.load(sys.stdin)
for p in d['query']['pages'].values():
    if 'imageinfo' in p: print(p['imageinfo'][0]['url'])
"
```

### 方法三：Python requests（适合脚本内使用）

```python
import requests
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}
proxies = {"http": "http://127.0.0.1:7897", "https": "http://127.0.0.1:7897"}

# 搜索特定Commons类别下的文件
url = "https://commons.wikimedia.org/w/api.php"
params = {
    "action": "query",
    "list": "categorymembers",
    "cmtitle": "Category:Ball_mills",
    "cmlimit": 20,
    "cmtype": "file",
    "format": "json"
}
r = requests.get(url, params=params, headers=headers, proxies=proxies, timeout=15)
data = r.json()
for member in data.get("query", {}).get("categorymembers", []):
    print(member.get("title"))

# 获取图片直链
titles = ["File:Example.jpg"]
params2 = {"action": "query", "titles": "|".join(titles),
           "prop": "imageinfo", "iiprop": "url|size|mime", "format": "json"}
r2 = requests.get(url, params=params2, headers=headers, proxies=proxies, timeout=15)
```

### HTTP 429 限流处理

当频繁请求 Commons API 或下载图片时可能遇到 HTTP 429：

```python
import time

# 方案1：使用浏览器级 User-Agent（比默认的 Python/requests UA 更不容易触发限流）
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}

# 方案2：每次请求间隔至少 2 秒
for name, url in image_urls:
    time.sleep(2)
    r = requests.get(url, headers=headers, proxies=proxies, timeout=30)

# 方案3：遇 429 自动重试
r = requests.get(url, headers=headers, proxies=proxies, timeout=30)
if r.status_code == 429:
    time.sleep(5)
    r = requests.get(url, headers=headers, proxies=proxies, timeout=30)
```

## MPO格式处理

从Commons下载的部分`.JPG`文件（如 `Ball_mill_with_steel_ball.JPG`）实际是MPO格式，python-pptx无法使用：

```python
from PIL import Image
img = Image.open('file.jpg')
img = img.convert('RGB')
img.save('file_converted.jpg', 'JPEG', quality=90)
```
