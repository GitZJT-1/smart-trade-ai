# 案例：陶瓷衬里焦炭筛板寻源（土耳其钢厂图纸，2026-09-29）

## 订单特征
- 品名：陶瓷衬里焦炭筛板（高炉装料设施，筛孔 28 mm，型号 TİP-3），图号 3.10.865.T.0204~0207.0
- 量：15 件（5 套×3）；单件约 140 kg（框架 99.7 kg + 棒条组件）；总重约 2.1 t
- 结构 = 焊接框架（S235JR/Q235B 板 8/10 mm）＋ 陶瓷棒条组件（Ø8×300 弹簧钢棒 55SiCrA/54SiCr6 穿 7 只 92% 氧化铝陶瓷环 Ø30×9，环氧粘接，胶层 0.5 mm）
- 关键工序：焊后钻 Ø8(+0.5/+0.3) 与 Ø11 孔；陶瓷环端面+棒体环氧粘接（钢-陶瓷粘接 ≥9–10 MPa）；喷砂 Sa2.5 + 环氧/聚氨酯涂装 RAL7047

## 这类产品的供应商地图（可复用）
1. **河南新乡集群** = 陶瓷棒条筛板/焦炭筛板主产区（振动筛之乡）。关键词直接搜「陶瓷棒条筛板」「陶瓷无动力焦炭筛」「高炉槽下 陶瓷筛板」。代表：新乡辉扬科技（主打陶瓷无动力焦炭筛）、大华耐磨振动、诚信振动、吉强通用、鑫兴冶金、高服股份、利星机械、豫新万泰。
2. **山东/江苏陶瓷件集群**（供瓷环/瓷片，可代粘接）：淄博（赢驰、科峰、启泰）、宜兴（华邦、伟民）、湖南精城特瓷（规模大、有出口）。关键词「氧化铝陶瓷环」「95/99 瓷环」。
3. **陶瓷+钢+胶一体化复合厂**（最贴本类工艺）：威海固德新材料等。
4. 辅料单独寻源：Ø8 弹簧钢棒（东北特钢等）、钢-陶瓷粘接环氧胶（郑州名拓、武汉恒瑞特）。

## 打法要点
- 三层：① 专业整件厂（陶瓷棒条/焦炭筛板，可直接整件报价）② 冶金筛板/振动设备厂（钢构+钻孔强，瓷环外协）③ 瓷件专业厂（按瓷环总量先报单价，作为整件报价谈判底牌）
- 瓷环是批量件（本例约 1.5 万只），先拿瓷环单价 + 模具费，再谈整件
- 必问三件：瓷环自制还是外购（要成分报告）／Ø8 与 Ø11 孔是否焊后加工／有无喷砂+环氧-聚氨酯涂装线
- 常见陷阱：清单条款与图纸涂装体系不一致（50–80 μm 环氧 vs 底50+中100+面50=250 μm）、弹簧钢牌号两处表述不同 → 投标前书面澄清
- 重量/孔数等底盘数字若无图面总重，按 BOM 分件重量累加或按孔板孔数×单根重量推算，并在清单中标注「按图推算、以工厂核图为准」
