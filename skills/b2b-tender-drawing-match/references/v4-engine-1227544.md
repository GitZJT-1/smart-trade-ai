## 阶段 3：单文件匹配（v4 变体集）

匹配顺序：PN（变体 norm 精确）→ VER（变体互含 len≥8）→ REV（剥版本后缀）→ NAME。

```python
def variants(pn):
    n = norm_pn(pn)
    out = {n}
    m = re.search(r"([а-яё]{2,})(\d)", n)   # 粘连拆分 квде85->квде.85
    if m: out.add(n[:m.start()] + m.group(1) + "." + n[m.start()+len(m.group(1)):])
    out.add(re.sub(r"\.[а-яё]{1,6}$", "", n))   # 剥 .гч/.м 尾部
    out.add(re.sub(r"[а-яё]{1,6}$", "", n))     # 剥无分隔符尾部字母 2745гч->2745
    out.add(re.sub(r"(\.[0]+)+$", "", n))       # 剥尾零 .00
    out |= {canon(x) for x in list(out)}
    p = pure_digits(n)                          # 纯数字主干 len≥8 才收
    if len(p) >= 8: out.add(p)
    return {x for x in out if len(x) >= 3}
```

候选提取关键：
- lib/JSON 共用 `[A-Za-zА-Яа-яЁё]{0,4}[-]?\d[...]{2,}` 中间段正则（**贪婪 `{2,}`，禁 `{2,}?`**）
- 提取后 `re.split(r"[_()]", t)[0]` 截断：`_`/`(` 之后是名称不是图号
- name_related 用 v21 对称降级（见 SKILL.md 第 4 节）
