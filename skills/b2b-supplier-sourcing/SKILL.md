# B2B 供应商寻源与询价

两条主线，通常按 A → B 串起来：

- **A 找谁询价**：为具体订单找一批「值得询价」的厂商，按匹配度分层输出推荐清单
- **B 怎么询价**：发询价邮件 + 生成询价表 + 回收比价

## 使用场景

**A 寻源**

- 现有供应商反馈不理想（拒单 / 报价无优势 / 联系无果），需要换一批
- 新订单需要从头找加工商 / 材料商
- 需要按工艺路线（CNC / 冷挤压 / 专业电极厂）分别找备选

**B 询价**

- 从客户需求或备件清单生成采购询价
- 发送包含询价明细的邮件给供应商，或存草稿供后续发送
- 参考已有已发邮件的格式和语气（「按已发件格式」）

---

## A. 寻源与推荐（7 步）

### Step 0 — 先确认订单上下文（最重要，2026-08-24 教训）

用户说"找厂商"时，**先查历史确认当前活跃的是哪个订单**：
- 查 trade.db conversations 表（`<trade 数据目录>/trade.db`，company_id 按当前公司）最近对话，或 session_search
- 用户常同时并行多个订单（如 1348795 密封件、TU1 无氧铜电极），推荐对象搞错 = 整份清单作废
- 用户说"这段对话上文是 X 订单" = 明确纠正，立即换订单重新做

### Step 1 — 调取订单参数

读询价单 xlsx / 图纸 / 数模，提取：数量、材质（牌号+标准）、单重/总重、关键尺寸、公差、粗糙度、金额量级。这些是匹配度评估和话术的底盘数字。

### Step 2 — 梳理历史推荐与反馈

查历史对话中已推荐过的厂家及其反馈，归类：
- **拒单**（如"订单量太大做不了"）→ 排除
- **产能不够** → 排除
- **报价/交期无优势**（超大厂盘口错配）→ 排除或降级为"杠杆"
- **联系无果** → 排除
生成「已排除名单」，新清单不得重复。

### Step 3 — 实时搜索新候选

按订单特性组合关键词 web_search（如"无氧铜 电极 加工厂""铜电极 CNC 定制 电话"），换多个区域/工艺关键词多轮搜。每条候选必须核实：公司全名、所在地、主营/工艺、联系方式（电话/微信/邮箱/官网/1688 店铺）。

### Step 4 — 匹配度评估（用户铁律 2026-08-19）

| 厂家盘口 | 对订单的态度 |
|:--|:--|
| 超大厂（日产百万级） | 会接但报价/交期无优势，订单占它营收 0.1% 上下 → 只当杠杆 |
| 中型专业厂（CNC/电极/车削专业） | 订单可能是它当季度大客户 → 首选 |
| 中小厂 | 吃不下大单（总重/产能）→ 排除 |

匹配度星级标注（★~★★★★★），优先推对订单量级重视度高的中型厂。

### Step 5 — 分层推荐

- **第一梯队**：正式询价（附图纸+询价单），3-5 家
- **第二梯队**：发图评估工艺可行性（如冷挤压评估），当杠杆
- **第三梯队**：材料商比价（走自购料模式时）

### Step 6 — 生成 xlsx 落盘

**Sheet1 推荐清单**：列 = 梯队 | 厂家 | 所在地 | 主营/工艺 | 匹配度（订单 vs 盘口） | 联系方式 | 询价要点/备注。按梯队填底色。
**Sheet2 询价策略与话术**：订单底盘数字（话术用）、分批发打法、报价要求（结构价+铜价联动+有效期）、必问三件事、打样条款、已排除名单、跟进节奏。
落盘位置：订单相关目录（如 `产品规格\{品名}询价\` 或任务文件夹），文件名带日期。

### Step 7 — 汇报

只讲：交付物位置 + 清单要点（梯队、厂家数、联系方式代表）。不夹杂搜索过程/验证过程/技术说明。

## B. 发询价（邮件 + 询价表）

### 邮箱接入

企业邮箱（网易企业邮）的服务器地址、授权码、文件夹 UTF-7 编码（已发送 `&XfJT0ZAB-`、草稿 `&g0l6P3ux-`）、imaplib 读写模板、常见登录错误码对照，统一放在技能 **b2b-mail-capture** 的 `references/corporate-email-imap.md`（同一套知识只维护一份）。要发信/读已发送格式时先读那份文档。

### 步骤

1. 读取用户提供的备件清单源文件（xlsx / 图纸 / 询价单）
2. 用户说「按已发件格式」→ 用 IMAP 连企业邮箱、读**已发送**文件夹最新询价邮件，提取结构与语气后复刻
3. 按指定模板排版生成**询价表 xlsx**
4. 按已发件格式生成邮件正文
5. 把邮件 `append` 到**草稿箱**（或按用户指示直接发送），保留往来记录
6. 告知用户附件需人工确认后再发

### 询价邮件标准结构

问候 + 自我介绍 + 项目背景（如 NLMK 项目）+ 询价清单 + 报价要求（结构价 / 有效期 / 交期 / 付款方式）+ 落款

### 询价表格式（8 列，跟随用户模板）

| 序号 | 物料编码 | 物料全称及规格 | 单位 | 数量 | 参考单价 | 小计金额 | 备注 |
|:-:|:-:|:-|:-:|--:|--:|--:|:-|

- 标题：**品牌备件询价表**（或按用户当次模板）
- 排版与命名规则必须与用户指定模板一致（列宽、合并单元格、表头底色）
- 供应商渠道分析结论**口头说明**，不塞进 Excel

### 注意

- 不编造物料编码和规格参数——一律取自源文件
- 发件人必须用用户真实邮箱信息，不虚构身份
- 格式匹配参考**已发邮件**，不凭猜测

## 注意与坑

- **多订单并行时先确认订单**（A/Step 0），这是本技能最大的坑
- 不编造联系方式；核实不实的标"需电话确认"
- 推荐表必须含匹配度维度，不只看质量效率（用户 2026-08-19 铁律）
- 报价要求统一"结构价"：材料费（按当日铜价单列）+加工费+工装费，附铜价联动条款、7 天有效期
- 打样条款：先 2~3 件样件验证关键尺寸，样件费我方出，合格后整单走
- 询价表与邮件附件分离：邮件正文给清单摘要，明细走 xlsx 附件
